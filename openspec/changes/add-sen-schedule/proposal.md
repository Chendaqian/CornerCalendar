## Why

公司项目约每三个月迭代一次，每个迭代的阶段计划以 Markdown 表格流转，普通日历无法快速表达 TR、宣讲、编码、提测、测试和上线等特殊语义。需要直接导入这些表格并在月历中按迭代、阶段和活动类型展示，不要求用户制作 ICS。

## What Changes

- 新增“森日程”特殊日程类型，数据入口为固定五列的 Markdown 表格，不提供森日程 ICS、URL 或网络订阅能力。
- 在设置分类中新增“森日程”，提供默认关闭的显示开关、“迭代名称”文本框、Markdown 表格多行文本框和已导入迭代列表。
- 一张 Markdown 表格对应一个迭代；支持保存多个迭代，同名再次导入时更新该迭代。
- 在主窗口刷新按钮旁新增“森”按钮，点击即时开启或关闭全部森日程显示，并体现当前状态。
- 根据表格序号应用固定特殊规则：TR1–TR5、宣、反、编、提、测、上、巡、总角标，以及阶段圆圈分组。
- 在日期格左上角显示森角标；“班/休”继续位于右上角，二者不重叠。不同角标使用独立颜色，角标字体优先使用自己的语义颜色。
- 开启森日程后，在普通工作日显示非选中态阶段圆圈：TR1–TR5 各一种颜色（序号 5–9 使用 TR5 色），序号 10 使用编码色、11 使用测试色、12–14 共用上线阶段色；周末、“班”和“休”日期不显示阶段圆圈，现有蓝色选中圆圈保持最高优先级。
- 阶段圆圈颜色与对应基础角标字体颜色保持统一；存在专属角标值时，角标字体使用自身颜色，圆圈仍使用所属阶段颜色。
- 悬浮提示展示用户输入的迭代名称、对应 TR/活动描述、自然日总天数和按中国日历计算的工作天数。
- 日历主窗口及日期相关子窗口整体放大 10%，内部布局、字号、日期格和控件按同一比例自适应放大；设置窗口尺寸保持原样。
- 点击同一天日期可切换日期详情窗口显示/关闭；点击主窗口天气摘要可切换天气窗口显示/关闭，天气窗口位于主窗口左侧且顶部对齐。没有阶段圆圈的日期也不显示森角标。
- 新增 Markdown 解析、多个迭代、日期计数、规则映射、开关及颜色选择的回归测试。

## Capabilities

### New Capabilities

- `sen-schedule`: 森日程 Markdown 导入、多迭代管理、主窗口开关、日期角标、阶段圆圈和悬浮提示行为。

### Modified Capabilities

无。

## Impact

- 影响设置持久化、日历 ViewModel、主窗口、设置窗口、日期格控件和 Light/Dark 主题资源。
- 新增纯本地 Markdown 表格解析与森日程模型，不引入网络请求或第三方依赖。
- 用户给出的 14 行表格作为标准解析和显示规则测试样例。
- 不改变现有中国日历、普通 ICS、刷新行为和“班/休”规则。
